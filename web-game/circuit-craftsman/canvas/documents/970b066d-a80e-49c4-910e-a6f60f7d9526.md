# 《电路小工匠》游戏设计文档

## 1. 游戏概述
《电路小工匠》是一款面向 4399 网页小游戏场景的原创休闲解谜游戏。玩家通过旋转电路方块，将电源连接到所有灯泡，修复小镇的照明设施。

- **游戏类型**：益智解谜、关卡制。
- **目标玩家**：喜欢短时思考与闯关的休闲玩家。
- **运行平台**：PC 网页浏览器，兼容移动端触屏。
- **体验时长**：单关约 1～3 分钟，完整流程约 60～90 分钟。
- **核心乐趣**：观察线路、规划连接，并获得整片灯光亮起的即时反馈。

## 2. 主题与目标
暴风雨后，小镇各处的电路出现故障。玩家扮演维修学徒，依次修复街道、学校、车站和广场的照明。

每关的目标是让所有指定灯泡同时通电。游戏不设置失败倒计时，玩家可以反复调整线路，直到找到解法。

## 3. 核心玩法
### 3.1 操作方式
- 鼠标左键点击可旋转方块，每次顺时针旋转 90°。
- 触屏设备点击方块，执行相同操作。
- 提供撤销、重开、提示和返回选关按钮；撤销恢复上一次旋转。
- 电源、灯泡和障碍块不可旋转，可操作方块通过边框与悬停效果区分。

### 3.2 电路规则
棋盘采用四方向网格。两个相邻格子的接口只有相向时才连通，斜向格子不能连接。

电流从电源出发，沿连通线路传播。灯泡与电源连通时亮起；所有目标灯泡亮起即通关。悬空接口不导致失败，闭合回路也不会扣分，不要求所有导线都通电。

### 3.3 方块类型
| 类型 | 规则 |
|---|---|
| 电源 | 固定位置与朝向，每关一个，提供电流起点 |
| 直线导线 | 连接两个相对方向，可旋转 |
| 转角导线 | 连接两个相邻方向，可旋转 |
| 三通导线 | 连接三个方向，用于分支供电，可旋转 |
| 十字导线 | 四个方向互通，不可旋转 |
| 灯泡 | 固定位置，只有一个输入接口 |
| 障碍块 | 无接口，不可操作 |

## 4. 关卡设计
首发包含 40 个手工设计关卡，分为四个区域，每个区域 10 关。
| 区域 | 棋盘规格 | 设计重点 |
|---|---|---|
| 街角 | 4×4 | 学习旋转、接口对接及单灯泡连接 |
| 校园 | 5×5 | 引入三通与多灯泡，学习分支供电 |
| 车站 | 6×6 | 引入障碍与干扰导线，增加路线判断 |
| 广场 | 7×7 | 综合运用多分支、绕行与局部回路 |

前 3 关通过方块高亮和点击动画引导操作，不使用长篇说明。每关预设至少一个可行解，再打乱可旋转方块的朝向；初始局面不得已经通关。多解关卡按实际通电结果判定，不强制匹配预设答案。

## 5. 评分与成长
每次有效旋转计为一步；撤销不减少累计步数，重开清零本次步数。每关配置并验证一个参考步数 S：通关获得 1 星，步数不超过 ⌈1.5S⌉ 获得 2 星，不超过 S 获得 3 星。

提示会高亮一个未通电灯泡，以及一处可帮助它接入电源的方块，不自动旋转。使用提示后，本次成绩最高为 2 星。提示依据当前局面的可行解生成，不能将另一种有效解误判为错误。

通关后解锁下一关，保留历史最高星级。星星用于解锁灯泡外观，不影响关卡难度或通电规则。

## 6. 界面与表现
- **选关界面**：显示四个区域、关卡编号、解锁状态与历史星级。
- **游戏界面**：顶部显示关卡与步数，中央显示棋盘，底部放置操作按钮。
- **结算界面**：显示本次星级、步数及“下一关”“再试一次”按钮。
- **视觉风格**：明快的二维卡通，浅灰棋盘搭配深色导线；通电线路显示黄色流动光点，灯泡同步发光，避免只靠颜色区分状态。
- **声音反馈**：旋转使用轻微机械声，灯泡亮起使用短提示音，通关播放简短旋律；支持静音。

## 7. 技术与存档
使用 HTML5 Canvas 或 Phaser 实现，关卡数据记录棋盘尺寸、方块类型、初始朝向和参考步数。每次旋转后从电源执行图遍历，更新线路与灯泡状态；无需模拟真实电路物理。

通过浏览器本地存储保存解锁进度、最高星级、外观和静音设置，不要求登录。棋盘按可用空间等比缩放，移动端点击区域尽量保持至少 44×44 CSS 像素，布局空间不足时缩减外围留白。

## 8. 验收标准
所有关卡必须经过可解性验证；旋转、撤销、重开和提示后的通电状态必须一致。多个灯泡同时点亮时只触发一次结算，结算期间禁止继续操作棋盘。

刷新页面后进度可恢复；存档缺失或损坏时能够回到默认进度。桌面与移动端均需验证棋盘不被遮挡、按钮可点击、音频受浏览器用户交互限制时不影响游戏运行。首版不包含广告、付费道具或在线排行榜。
