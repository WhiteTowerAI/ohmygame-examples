# Circuit Craftsman 成品素材

轻量 agent 案例仅保留 **47 张游戏实际使用的 WebP**。本目录是唯一成品目录，Canvas 直接引用同一份文件。加载画面与顶栏复用两张中英文 Logo，不保留大尺寸副本。

## 清单

| 目录 | 数量 | 内容 |
| --- | ---: | --- |
| `branding/` | 2 | 中文与英文 Logo |
| `characters/` | 6 | 全身角色、四种表情和伙伴 |
| `tiles/` | 9 | 电源、四种管道、亮灭灯泡、障碍和底板 |
| `buttons/` | 5 | 撤销、重开、提示、选关和设置 |
| `ui/` | 8 | 星星、结算与设置框、关卡格、蓝色和金色按钮 |
| `runtime/` | 4 | 已调色的街角、校园、车站和广场背景 |
| `props/` | 4 | 工具箱、告示牌、路灯和路锥 |
| `effects/` | 5 | 旋转、亮灯、三星、提示和电流反馈 |
| `thumbnails/` | 4 | 四区域缩略图 |

## 压缩与规格

43 张 PNG 转为无损 WebP，逐像素比对确认尺寸、Alpha 和可见 RGB 不变。原有四张背景 WebP 保留原字节；透明区域不可见的 RGB 不作为视觉差异。游戏成品合计约 4.75 MiB。

- 方块和操作按钮保持 `256×256`，表情保持 `512×512`，全身角色保持 `512×768`。
- 背景保持 `1536×1024`；中文 Logo 为 `384×144`，英文 Logo 为 `512×256`。
- 设置框保持 `768×544`，冰蓝内部不透明，框外透明；文字、开关及状态由界面动态绘制。
- 灯泡亮灭共用轮廓、透明度、底板、螺丝和灯座，只有玻璃内 10,059 个像素改变。
- 管身外径 `32`，银色内层 `28`，铜接口外宽 `40`、长度 `20`，几何契约保留在 `src/circuit-art-geometry.json`。

默认接口：电源向右、直线左右、转角右下、三通左右下、十字四向、灯泡向下。以中心顺时针旋转，每次 90 度；仅相向端口连通。游戏程序绘制接缝、通电路径和移动光点，不再保留未使用的 `wire-*-on` 原型图片。

## 接入与检查

`src/art-files.ts` 是加载与发布的唯一入口。`manifest.json` 记录稳定游戏键、名称、相对路径、尺寸、SHA-256、透明检查及接口定位；`validation.json` 记录本次压缩和运行验证。修改图片时同步更新清单和哈希。

运行 `npm test` 检查素材与游戏回归。普通文件头、尺寸、哈希和 Canvas 检查不需要系统工具；装有 `ffmpeg` 时追加解码像素测试。`npm run build` 仅发布这 47 张图片及所需许可证。

历史生成母版、参考图、加工图层、PNG 成品副本和预览合集已删除。两个精简 Canvas 保留设计与关键成品，生成历史为空。本案例不提供原图重新加工或独立素材 ZIP。
